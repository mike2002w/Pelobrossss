HOW XP WORKS
Every logged session pays 100 XP. Each working set adds 8. Every 100 lb moved (weight times reps, kg converted) adds 1. Cardio pays 3 per minute and 20 per mile. A new top working weight on any lift is a PR: 200 XP. Assist machines count sets but not tonnage, since a lower number is the harder set. Bodyweight work counts sets only. Warm-ups are free.
